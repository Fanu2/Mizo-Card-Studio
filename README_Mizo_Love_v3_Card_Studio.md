# ❤️ Mizo Love v3 — Card Studio

A PySide6 desktop application for learning Mizo romantic and affectionate
expressions and creating beautiful **Mizo-only PNG cards directly inside the app**.

## New Card Studio

Paste any Mizo text into the Card Generator and choose:

- Romantic Sunset
- Midnight Rose
- Dreamy Lavender
- Golden Love
- Ocean Heart
- Elegant Dark

Output sizes:

- 1080 × 1350 portrait
- 1080 × 1080 square
- 1920 × 1080 landscape

Then click **Generate Card** and **Save PNG**.

The generated artwork contains the Mizo text only, so the card is clean and
ready to share. The English meaning remains in the phrase library for your
private understanding.

## Run

```powershell
py -m pip install PySide6
py Mizo_Love_PySide6_v3_Card_Studio.py
```

## Workflow

1. Select a phrase in the Mizo library.
2. Read the English meaning.
3. Copy or paste the Mizo wording into Card Generator.
4. Choose a design and size.
5. Generate the preview.
6. Save the PNG.

## Accuracy

Reference, dictionary and practice entries are distinguished in the library.
Practice entries should be checked with a fluent Mizo speaker before being sent
as polished romantic messages.
